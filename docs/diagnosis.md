# 2026-11 업데이트 후 누락 진단

작성일: 2026-11-10. 검증 방법: HF CSV 5종 프로파일링, 크롤러 코드 검토, 사이트 실응답 확인.

## 공통 문제

1. **병합 시 정제 누락.** 민주당 CSV에서 2026-02-05까지의 행은 노트북 정제 규칙을 거쳤지만(괄호·%·줄바꿈 없음), 2026-02-06 이후 행은 대부분 미정제 상태입니다.
2. **조용한 누락.** 본문 공란은 `''`으로 반환되고 최종 `text != ""` 필터에서 제거됩니다. 실패 로그가 없어 누락 규모를 셀 수 없습니다.
3. **연속 실패 시 게시판 전체 중단.** 빈 페이지 3회, 연속 오류 10회에서 루프를 끝냅니다.
4. **파일명과 실제 범위 불일치.** 국민의힘 파일명은 `~2026-02-03`이지만 데이터는 2026-11-09까지입니다.
5. **CSV 손상.** 민주당 CSV에 `board_name`에 본문 조각이 들어간 행 19건(url NaN)이 있습니다.

## 정당별

### 조국혁신당 (`crawl_cj.py`): 현재 코드로는 목록 0건
- 사이트가 Next.js 클라이언트 렌더링으로 바뀌었습니다. 목록 정적 HTML에 기사 링크가 없고 "총 0 건"으로 나옵니다.
- 정규식 버그: `^/news/{board_path}/`에 `board_path="news/press-release"`를 넣으면 `^/news/news/press-release/`가 되지만, 실제 href는 `/news/press-release/N`입니다.
- 상세 파서(`div.editor.ck-content`)는 정상입니다.
- 수정안: 목록 내부 API를 찾거나 브라우저 렌더링 사용. 목록 상단의 "총 N건"을 검증 기준으로 씁니다.

### 더불어민주당 (`crawl_dp.py`, 노트북)
- 목록 `<time datetime>` 속성이 모든 항목에서 `2023-02-14`로 고정되어 있습니다. 스크립트가 속성을 먼저 읽어 날짜 필터와 조기 종료가 작동하지 않습니다. 최종 `date`는 상세 페이지 값으로 덮이므로 CSV 날짜는 맞지만 전체를 긁습니다.
- 사이트는 `CYBER` 쿠키를 심고 307로 되돌립니다. 쿠키 없이 요청하면 리다이렉트 루프에 빠집니다. 쿠키를 유지하면 정상 응답이 옵니다.
- 본문 공란 1,473건: 예시 페이지는 사이트 자체가 비어 있었습니다(BOM만 있음). 첨부파일에 본문이 있을 가능성이 큽니다.
- 노트북 정제 규칙이 괄호·%·따옴표를 전부 제거해 원문을 훼손합니다.
- 보도자료 게시판은 2025-06 이후 월 10~20건이고, 2022-01~2023-07에 공란이 몰려 있습니다. 사이트 게시 건수와 대조 필요.

### 국민의힘 (`crawl_ppp.py`): 목록 정상, 본문 공란이 문제
- 목록 구조(board-tbl, 4열, 날짜 열)는 현재도 일치합니다. 2026-11-09까지 수집되어 있습니다.
- 본문 공란 376건(대변인 게시판, 주로 2022~2023). HTTP 200인데 본문이 없는 응답이 원인으로 보입니다. 빈 본문과 요청 실패를 구분하지 않아 재시도 대상에서 빠집니다.
- 첫 요청 연결 리셋이 한 번 있었습니다. 재시도 간격 1초가 짧습니다.
- 공지글이 오래된 날짜로 상단에 붙으면 조기 종료될 위험이 있습니다(이번에는 미확인).

### 민주당 — 추가 확인 (2026-11-10, 2번 작업)
- **누락의 주원인 확정:** 보도자료 게시판 목록은 4,593건인데 기존 CSV는 3,034건입니다. 기존 CSV에 없는 1,559건 중 2025년 751건, 2026년 362건이 많습니다.
- 샘플 30건을 확인하니 **29건은 본문이 공란이고 PDF 첨부에만 내용이 있었습니다(1건은 HWP).** 기존 파이프라인이 본문 공란 행을 최종 필터에서 버리면서 이 게시물들이 빠졌습니다.
- 수정: 본문이 비면 첨부(PDF는 pdftotext, HWP는 hwp5txt)에서 텍스트를 뽑습니다. 샘플 40건에서 공란 0건, 날짜 불일치 0건이었습니다.
- 목록 날짜 `<time datetime>` 속성은 쓰지 않고 화면 날짜를 씁니다. 쿠키는 requests.Session으로 유지합니다.
- 전체 규모(목록 기준, 2026-11-10 측정): 보도자료 약 4,593건, 논평·브리핑 약 57,559건, 모두발언 약 8,686건. 상세 수집은 시간이 오래 걸리므로 체크포인트 방식으로 이어서 받습니다.
- 텍스트는 원문 그대로 저장합니다. 괄호·% 등 정제는 파이프라인의 별도 단계에서 합니다.
